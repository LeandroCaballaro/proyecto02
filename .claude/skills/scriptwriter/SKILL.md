# The Scriptwriter

## Entrada
Gancho elegido (o tema), duración objetivo (15/30/60/90 s), plataforma, CTA.

## Estructura
1. **Gancho (0–3 s)**: frase + visual con interrupción de patrón.
2. **Contexto/problema (3–8 s)**: por qué importa.
3. **Desarrollo**: 3 puntos máximo, un cambio visual cada 2–4 s; abre bucles ("y el tercero es el que nadie hace").
4. **Payoff**: la respuesta/transformación prometida.
5. **CTA (últimos 3 s)**: una sola acción.

## Reglas
- ~2.5 palabras por segundo; ajusta el texto a la duración.
- Frases cortas, lenguaje hablado, sin relleno.
- Cumple la promesa del gancho.

## Salida
Tabla: Tiempo | Audio/voz | Plano/cámara | Texto en pantalla | B-roll/SFX. Después: número de palabras, duración estimada y notas de edición (ritmo, música, subtítulos).
